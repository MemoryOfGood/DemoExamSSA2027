# 5. Настройте безопасный удаленный доступ на серверах HQ-SRV и BR-SRV

* для подключения используйте порт 2027:
	* разрешите подключения исключительно пользователю sshuser;
	* ограничьте количество попыток входа до двух;
	* настройте баннер «Authorized access only»;


>[!TIP]
> Для задания стоило бы также создать пользователя sshuser на HQ-CLI

Редактируем /etc/openssh/sshd_config
```bash
nano /etc/openssh/sshd_config
```

Изменяем следующие параметры 


>[!Warning]
> Обратите внимание чтобы работали параметры они должны быть не как комментария т.е без знака ```#```

>[!TIP]
> Можно просто записать в самом начале
```bash
Port 2027
PermitRootLogin no
MaxAuthTries 2
Banner /etc/openssh/banner
```

Добавляем строчку
```bash
AllowUsers sshuser
```

Сохраняем и выходим из файла (crtl+x, y, enter)

Пишем баннер для ssh-server
```bash
echo Authorized access only > /etc/openssh/banner
```

После чего перезапускаем службу
```
systemctl restart sshd
```
