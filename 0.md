### ISP, HQ-SRV, BR-SRV, HQ-CLI
> [!WARNING]
> Для HQ-CLI сперва нужно перейти в суперпользователя
> ```
> su -
> ```

Редактируем файл оболочки
```
nano .bashrc
```
и добавляем строчку 
```
export EDITOR=nano
```
