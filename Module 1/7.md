# 7. Обеспечьте динамическую маршрутизацию на маршрутизаторах HQ-RTR и BR-RTR и межсетевом экране BR-FW
* сети одного офиса должны быть доступны из другого офиса и наоборот:
	* разрешите выбранный протокол только на интерфейсах туннеля на HQ-RTR и BR-RTR, на BR-FW используйте в OSPF только интерфейс в строну BR-RTR;
	* используйте OSPF для маршрутизации;
	* используйте аутентификацию в OSPF на маршрутизаторах HQ-RTR и BR-RTR;
	* в качестве пароля используйте P@ssw0rd;
	* пароль должен передаваться с использованием хешированного ключа MD5;
	* сведения о настройке и защите протокола занесите в отчёт;

Для настройки между HQ-RTR и BR-RTR

### HQ-RTR
Создаём ```area```
```
routing/ospf/instance/add
routing/ospf/area/add area-id=10.10.10.0 instance=ospf-instance-1
```
Указываем  ```router id```
```
/routing/ospf/instance/set router-id=10.10.10.1 ospf-instance-1
```
Добавляем ```OSPF interface template```
```
routing/ospf/interface-template/add area=ospf-area-1 interfaces=HQ-BR,vlan100,vlan200 auth=md5 auth-key=P@ssw0rd
```

### BR-RTR
Создаём ```area```
```
routing/ospf/instance/add
routing/ospf/area/add area-id=10.10.10.0 instance=ospf-instance-1
routing/ospf/instance/add
routing/ospf/area/add area-id=192.168.3.0 instance=ospf-instance-2
```
Указываем  ```router id```
```
/routing/ospf/instance/set router-id=10.10.10.2 ospf-instance-1
/routing/ospf/instance/set router-id=192.168.3.1 ospf-instance-2
```
Добавляем ```OSPF interface template```
```
routing/ospf/interface-template/add area=ospf-area-1 interfaces=HQ-BR,ether2 auth=md5 auth-key=P@ssw0rd
routing/ospf/interface-template/add area=ospf-area-2 interfaces=HQ-BR,ether2
```

### BR-FW
Создаём ```area```
```
routing/ospf/instance/add
routing/ospf/area/add area-id=192.168.3.0 instance=ospf-instance-1
```
Указываем  ```router id```
```
/routing/ospf/instance/set router-id=192.168.3.2 ospf-instance-1
```
Добавляем ```OSPF interface template```
```
routing/ospf/interface-template/add area=ospf-area-1 interfaces=ether1,ether2
```

В конце на каждых из трёх прописваыем для вывода соседей в OSPF:

### HQ-RTR, BR-RTR и BR-FW
```
routing/ospf/neighbor/print
```
